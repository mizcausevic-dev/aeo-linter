AEO Linter

Rule categories explained in operator language.

The explain mode keeps the CLI legible for people who need the intent behind each lint category.

cargo run -- explain (exit 0)
AEO Linter Rule Set
  - llm.txt presence and freshness
  - entity identity and sameAs linkage
  - claim-to-source evidence coverage
  - Schema.org relationship hygiene
  - answer-surface depth (FAQ, comparisons, examples)
  - citation depth and policy posture

The goal is not only to validate syntax. It is to make content and metadata easier for answer engines to cite without drifting into hallucinated summaries.
